AWS assignment 1:Deploy static website

step 1:Configure Instance
Name: StaticWebsite
AMI: Amazon Linux 2023(first default)
Instance Type: t3.micro
use existing pem key

step 2:Configure Security Group
a.click edit
b.add security group rules
ssh,http,https use (anywhere(=)

step 3:Launch instance
step 4:view all instances
step 5:copy IPV4 address

step 6:select and connect
step 7:Update Amazon Linux(optional)
command:sudo yum update -y

step 8:Install Apache Web Server
commands:
1.install:sudo yum install httpd -y
2.start:sudo systemctl start httpd
3.enable:sudo systemctl enable httpd
4.check status:sudo systemctl status httpd

step 9:Test Public Access
http://YOUR_PUBLIC_IP

step 10:Create Static Website
Move to web directory:cd /var/www/html
Create webpage:sudo nano index.html

code:
<!DOCTYPE html>
<html>
<head>
<title>AWS Static Website</title>

<style>
body{
    background-color:#f2f2f2;
    text-align:center;
    margin-top:100px;
    font-family:Arial;
}

h1{
    color:blue;
}
</style>

</head>

<body>

<h1>Welcome to My AWS EC2 Website</h1>
<p>Static website hosted successfully using Amazon Linux.</p>

</body>
</html>
